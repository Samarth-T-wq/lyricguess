# LyricGuess — Experiment Backlog

Experiments to run once V1 is live and instrumented. Each has a hypothesis and a
metric it moves. Not yet run — this is the plan.

## E1 — Round count: 10 vs. 7
Hypothesis: shorter sessions raise completion rate for casual players.
Measure: session completion rate, replay rate.

## E2 — Timer mode (opt-in)
Hypothesis: a countdown adds excitement and replay pull for competitive users.
Measure: replay rate, session length, error rate (guardrail).
Note: timer is out of scope for V1; this is a post-launch test.

## E3 — Feedback intensity
Hypothesis: bigger, more satisfying correct/incorrect animations increase
"one more round" behavior.
Measure: replay rate, rounds per session.

## E4 — Difficulty default
Hypothesis: defaulting to Easy (vs. no default) lowers first-round drop-off.
Measure: time-to-first-round, completion rate.

## E5 — Snippet length on Hard
Hypothesis: current Hard snippets are too short and frustrate players.
Measure: Hard accuracy curve, mid-session drop-off on Hard.
