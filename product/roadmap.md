# LyricGuess — Roadmap

## Now (V1 — MVP)
The full brief scope: genre/difficulty/mode selection, 10-round session, scoring,
streaks, results, play again, error handling, analytics. Goal: validate the loop.

## Next (post-validation, if V1 metrics are good)
- Timer / speed mode (experiment E2)
- "Guess the Next Line" third mode
- Score sharing (screenshot-friendly results, share link)
- Difficulty/snippet tuning based on real accuracy curves

## Later
- Accounts + persistent stats
- Leaderboards (Competitive Deb's ask)
- Daily challenge (one shared puzzle a day, Wordle-style)
- Streak multipliers and richer scoring

## Someday / dependencies
- Proper lyric licensing (required before any public/commercial scale — see
  brief §12). This gates going beyond fair-use short snippets.
- Expanded genre catalog and larger dataset.
